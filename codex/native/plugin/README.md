# QA Guide 0.5.2

この配布パッケージは、固定のdist/server.mjsをNode.js 22以降で起動するstdio MCPと、会話用QAパネルです。実行時のnpm依存は不要です。導入方法とビルドは一つ上のREADME.mdを参照してください。

対象タスク、現在状態、決める事項、完了条件、背景、選択の結果・利点・代償、おすすめの理由を表示します。おすすめは自動選択しません。回答は本人が確定したときだけ現在の会話へ送ります。実行承認を付与しません。

明確な回答/再説明の送信拒否では明示的に再試行できます。到着不明では二重送信を止めます。再説明はquestionId・revision・requestIdで照合し、古い・重複・未依頼の返却を無視します。

各UIの状態はメモリだけです。履歴DB、秘密情報、任意ファイルの読取り、外部AI API、実行hooksを追加しません。元のMIT ©2026 aieo-productのLICENSEを保持し、バンドル依存のライセンスはTHIRD_PARTY_NOTICES.mdにあります。
